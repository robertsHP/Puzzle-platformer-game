# Puzzle Platformer Game
Simple puzzle platformer that works for Godot 4.2 (C# programming language). <br>
<br>
Controls: <br>
A or Left arrow - Move left <br>
D or Right arrow - Move right <br>
W or Up arrow - Press button on a wall <br>
Space - Jump <br>
Enter - Restart (If the player died) <br>
