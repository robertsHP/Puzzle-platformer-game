# Puzzle Platformer Game
Simple puzzle platformer that works for Godot 4.2 (C# programming language).

Controlls:
A or Left arrow - Move left
D or Right arrow - Move right
W or Up arrow - Press button on a wall
Space - Jump
Enter - Restart (If the player died)
